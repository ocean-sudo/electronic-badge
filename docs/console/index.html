自动切换图片

连接设备后读取自动切图设置。

自动切图和随机顺序默认关闭，间隔 10 秒；可设 2～3600 秒，修改后点击应用。设置保存在徽章，关闭网页或拔掉 USB 后仍有效。随机顺序也用于手动下一张：新取图每轮遍历全部有效图片，两张以上不连续重复；人工回看和前进历史重放会重现旧图，但不改变洗牌进度。上一张回到实际播放历史（最多前 5 张）；返回后下一张先重放前进历史。历史仅在 RAM，普通重启清空并从上次手动选择开始；PMIC 关机后的冷启动不保留临时轮播当前图片，已保存设置保留，RAM 历史清空且随机轮次重置。熄屏或打开菜单时暂停自动切图，返回后重新计时；至少需要两张图片。

图片转场与持续运动

连接设备后读取动画设置。

图片转场可选直接切换、黑场淡变、水平推入或径向涟漪；涟漪以低成本径向边缘扩展，避免昂贵的逐像素混合，但边缘过渡较硬。默认黑场淡变、持续顺时针旋转，每圈 24 秒；仅持续旋转可调整周期（8～120 秒，数值越小越快），切换其他模式会保留周期供切回使用。旋转是画面效果，不只用于防烧屏；也可选微移、关闭运动或重力跟随。重力跟随让图片底部朝向重力方向；平放时等待有效方向，设备菜单保持固定。熄屏、菜单及图片传输会暂停动画。后台动画不延长闲置熄屏计时；常亮仍有 AMOLED 老化风险。修改后点击应用，设备状态与未保存草稿分别显示。

自动熄屏 / 自动关机 · 按供电方式设置

连接设备后读取自动睡眠设置。

0 表示不自动熄屏 / 自动关机；其他值为 5～86400 秒（最长 24 小时）。全新配置默认插电 15 秒、电池 0（一直显示），已有保存设置保持不变。触摸、按键和主动控制会重新计时，轮播、图片动画、网页后台刷新和预览回读不会续时；菜单打开也会按当前供电方式处理超时。插拔电源重新计时，但不会自动唤醒。设置保存在徽章，关闭网页也有效。USB/VBUS（包括充电器）与电源检测异常时，睡眠请求只熄屏并保持 USB 控制在线；电池供电时，手动 SLEEP、闲置超时，以及 USB 熄屏后拔线转为电池供电，都会在当前操作完成、输入释放及 PMIC 就绪检查通过后请求 AXP2101 PMIC 软件关机，不进入 ESP32 深度睡眠。PMIC 关机断开 USB，网页无法查询或唤醒；按住 POWER 约 2 秒冷启动，触屏不能唤醒。

图片界面左滑下一张、右滑上一张、上滑打开菜单；运行时短按 BOOT 也可打开或关闭菜单。主菜单分为 PLAYBACK（自动切图、随机、间隔及历史切图）、DISPLAY（亮度与 ANIMATION 动画页）、TIMEOUT（插电闲置熄屏 / 电池闲置 PMIC 关机，0 为关闭）。菜单内 SLEEP 在电池供电时请求 PMIC 关机，在 USB 或电源未知时只熄屏并保持在线；设备等待触控、按键、BOOT 和串口命令释放，并确认 PMIC 已就绪后再关机，条件不满足时不会切断电源。各页顶部显示电池百分比与实际充电状态，不把 USB 连接当作充电。BACK 返回上一级（动画 → 显示 → 主菜单），主菜单 BACK 返回图片；任意菜单页下滑或点击上方「关闭设备菜单」直接关闭整个菜单。在屏幕左侧中部边缘起手向右滑也可返回上一级，按钮上起手不会触发边缘返回。这里回读固件实际菜单帧，不是网页模拟或光学屏幕回读；成功上传新图会退出菜单。
