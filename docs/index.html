功能概览

从电脑准备画面，设备负责展示。

01 挑选与裁切

导入 JPG、PNG 或 WebP，在圆形预览中调整构图。选择图片不会自动上传，明确确认后才传输。

02 设备端播放

管理图片、亮度、动画与熄屏。轮播由固件执行，关闭电脑服务后仍可继续。

03 完整性校验

图片传输带有 CRC 校验；网页可读取设备保存的 JPEG 成品，目录使用稳定 ID。

本地运行

控制服务在你的电脑上。

图片处理与 USB 串口服务只在用户本机运行。GitHub Pages 是静态项目介绍，不连接徽章，也不提供在线控制台。

  1. 安装 Python 依赖并连接 USB
  2. 在本机启动服务并打开网页
  3. 裁切图片，确认后上传到徽章

实测与边界

说明能力，也说明限制。

466 × 466JPEG 成品画布
0.85浏览器 Canvas 编码质量参数
228–284 ms42 张自然照片解码路径实测

设备用 ESP32-S3 ROM 软件 TJpgDec 解码 JPEG。WebP 输入由浏览器转码，不由设备解码。解码测量含文件读取、CRC 校验及 RGB 转换；会随图片和 I/O 变化，不是性能保证。
